# 贝加尔55径

**Baikal 55 — Lake Baikal West Shore, 55km, 3 Days**

贝加尔湖西岸一条55公里的徒步路线，从大戈洛（Большое Голоустное）到利斯特维扬卡（Листвянка）。三天，重装，全程无信号。

> 一边是来时的你，另一边还是你，中间隔了一个湖。
> 走完了，很多事情也就过去了。

---

## 路线概览

| 项目 | 说明 |
|------|------|
| 距离 | 55公里 |
| 天数 | 3天 |
| 方式 | 重装徒步，全程露营 |
| 地点 | 贝加尔国家森林公园，贝加尔湖西岸 |
| 签证 | 俄罗斯对中国公民免签 |
| 起终点 | 大戈洛 → 大科蒂 → 利斯特维扬卡 |

## 线路特点

- 湖水透明度达40米
- 沿途森林、岩岸、悬崖、湖湾交替
- 全程无公路并行，无商业开发
- 国内户外圈知名度不高，适合想安静走路的人

## 历史背景

这条路走过的土地，也是1825年十二月党人流放之路的一部分。两百年前，一群俄国贵族精英被流放到西伯利亚。两百年后，有人主动走同一片土地——不是因为被赶走，而是有些东西自己放不下，只能留在这里。
