# 贝加尔50径

**Baikal 50 — Lake Baikal West Shore, 50km, 3 Days**

贝加尔湖西岸一条50公里的徒步路线，从利斯特维扬卡（Листвянка）到大戈洛（Большое Голоустное）。三天，重装，绝大部分路段无信号。

> 一边是来时的你，另一边还是你，中间隔了一个湖。
> 走完了，很多事情也就过去了。

---

## 路线概览

| 项目 | 说明 |
|------|------|
| 距离 | 50公里 |
| 天数 | 3天徒步（全程6天） |
| 方式 | 重装徒步，全程露营 |
| 地点 | 贝加尔国家森林公园，贝加尔湖西岸 |
| 签证 | 俄罗斯对中国公民免签 |
| 起终点 | 利斯特维扬卡 → 大科特 → 大戈洛 |
| 出行时间 | 6-9月，批次视报名情况确定 |

## 线路特点

- 湖水透明度达40米
- 沿途森林、岩岸、悬崖、湖湾交替
- 全程无公路并行，无商业开发
- 国家公园内成熟路线，路标清晰，路线周围不会出现大型野生动物
- 国内户外圈知名度不高，适合想安静走路的人

## 行程

| 天 | 安排 |
|----|------|
| Day 1 | CA869 北京 → 伊尔库茨克，入住伊尔库茨克中心酒店 |
| Day 2 | 乘车前往利斯特维扬卡（利村），参观贝加尔湖博物馆，住利村 |
| Day 3 | 利村 → 黑谷营地，徒步16公里 |
| Day 4 | 黑谷营地 → 大卡季角2号营地，徒步18公里（大科特村、斯克佩瑞尔悬崖、鬼桥） |
| Day 5 | 大卡季角2号营地 → 大戈洛，徒步16公里，乘车返回伊尔库茨克，住中心酒店 |
| Day 6 | 参观十二月党人纪念馆，CA870 伊尔库茨克 → 北京 |

## 费用

**16,200 元 / 人**（5-6人成团，1名领队 + 1名协作）

**包含：** 往返国航 CA869/CA870 机票（托运 1×23kg + 手提 1×7kg）、酒店住宿（共3晚单人大床房：伊尔库茨克中心酒店四星 + 利斯特维扬卡贝加尔酒店四星）、全程标准餐（徒步外为标准俄餐）、国家公园手续及相关门票、接送机及全程用车、领队服务、全程翻译、境外及户外意外伤害险（京东安联麦哲伦计划：医疗运送送返200万、身故伤残100万）。

**不含：** 个人消费、徒步个人装备（可代租，费用自理）。

## 历史背景

这条路走过的土地，也是1825年十二月党人流放之路的一部分。两百年前，一群俄国贵族精英被流放到西伯利亚。两百年后，有人主动走同一片土地——不是因为被赶走，而是有些东西自己放不下，只能留在这里。
